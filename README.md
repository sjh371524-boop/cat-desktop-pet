# Codex Cat 桌宠

这是一个可持续修改的 Windows 原生桌宠项目。主桌宠采用 WPF 逐像素透明窗口，支持鼠标拖动、屏幕亮灭计时、托盘、右键云朵气泡、实时天气，以及与互动气泡同尺寸的本地虚拟算数机。

当前程序已经可以独立运行，并已使用用户照片中的三花猫作为正式角色。最新身份基准是 `template-input/pixel-calico-heterochromia.png`：正面看左眼保留黄绿色，右眼为淡蓝色；粉鼻、白色胸腹、不对称黑橘头斑、原有体型和橘色尾尖均保留。转身时保持同一只眼睛的颜色，闭眼时不额外绘制虹膜。动作关键帧采用精细像素风和真实透明背景；程序化开发猫只作为源码级故障回退。`猫.jpg` 是保留的原始用户照片，不再是未来眼色的基准。

## 直接启动

双击根目录中的 `启动桌宠.cmd`。脚本会先编译，然后启动：

```text
dist\CodexCat.exe
```

当前电脑已经具备所需的 Windows 桌面运行库和系统 C# 编译器，不需要额外安装 Python、Node.js 或第三方 GUI 框架。

桌宠默认出现在主屏幕右下方。左键拖动，右键打开互动气泡；托盘菜单可以重新显示桌宠、摸摸它、打开算数机或退出。如果桌宠已在运行但被隐藏，再次双击 `启动桌宠.cmd` 会直接唤醒现有窗口，不会重复编译或创建第二只桌宠。互动气泡采用 400×330 的统一设计画布：内部四张功能卡片使用相同宽度和 6 像素间距，并同时校验云朵朝左、朝右两种方向，保证圆角边框始终落在不透明云层之内。气泡右侧的淡红色“放/缩”圆形控件分为左右两个点击区域：左半边“放”会按当前大小放大 20%，右半边“缩”会按当前大小缩小 20%。其下方依次是橙黄色“退下”圆和淡绿色“保持清醒”圆；三枚圆形控件也完整放在云朵背景内。“退下”会执行完整退出清理并结束 `CodexCat.exe`，淡绿色圆则切换是否允许定时待机自动进入特殊睡眠。桌宠、气泡与算数机同步缩放，程序会按当前显示器工作区动态限制最小与最大尺寸，并把选择保存到 `config/settings.local.json`。

## 已实现的行为

| 状态 | 触发条件 | 动画与交互 |
| --- | --- | --- |
| 默认站立 | 启动、普通动作结束 | 面向用户，保留呼吸和眨眼；没有特殊动作时，双眼平滑追踪桌面鼠标，上下左右及斜向注视，保留异瞳 |
| 待机动画1 | 每累计亮屏使用 60 秒 | 1.5 秒内坐下并伸出“预计气泡方向”的反侧前爪，眯眼微笑、伸出短舌舔爪，再收舌收爪；不会增加五分钟默认待机计数 |
| 随机摇尾待机 | 上次本动作结束后随机等待 10–20 秒 | 保持正常异瞳站立形象，2 秒内轻柔上下摇尾两个来回；第一回结束、第二回开始时眨眼一次，并在第二回结束前睁开。摇尾幅度为喵叫回应的一半；尾根固定在臀部锚点，摆幅从根部向尾尖渐进增加，并由身体层覆盖连接缝；优先级高于随机摇耳 |
| 随机摇耳待机 | 独立计时，上次本动作结束后随机等待 10–20 秒 | 保持正常异瞳站立和原有体型，耳根基本不动、耳尖以约 2.25° 的自然小幅度摆动；双耳在 2 秒内轻柔摇晃两个完整来回，每个来回 1 秒。第一次结束、第二次开始的交接点复用随机摇尾的同一套眨眼动作，并在第二次摇耳结束前睁开，再平滑恢复原位。与随机摇尾同时到点时播放摇尾；正在摇耳时若摇尾或更高优先级待机到点，也会平滑切换，跳过的摇耳不补播 |
| 位移步态 | 鼠标左键拖动 | 超过 2.5 个桌面像素的真实位移后才识别方向，先播放正面到左/右侧身的专用转身帧，再进入四脚对角交替的侧身步态；头、耳朵和视线同步转向，眨眼独立于脚步循环。松开鼠标后反向播放侧身回正面的收势帧，不再瞬间跳回站立 |
| 舔爪待机 | 每累计亮屏使用 5 分钟 | 2 秒内坐下、抬爪、转头、闭眼、张嘴和伸舌舔爪 |
| 特殊睡眠 | 第六个 5 分钟节点替代舔爪 | 2 秒内逐渐降低身体、蜷缩并用尾巴包住身体，闭眼睡眠且显示跟随状态的 `Zzz` |
| 睡眠锁定 | 特殊睡眠开始后 | 拖动不生效；猫咪下方以小间距紧贴显示紫色填充、深紫细圆角描边的正常字重卡通“睡着了”文字，保留清楚的汉字笔画细节 |
| 逐渐醒来 | 右键气泡中的“叫醒它” | 2 秒从蜷缩状态逐步恢复站立；随后重新开始五次普通待机、一次特殊待机的周期 |
| 摸摸它·享受摸头 | 右键气泡中的“摸摸它” | 先播放 2 秒 `Petting`：完整像素手掌从互动气泡所在的一侧进入，指尖落在两只耳朵之间，并完成两次清晰的纵向抚摸和少量顺毛横移；猫咪闭嘴、眯眼微笑，把头歪向手掌，手和猫均在动作首尾缓入缓出 |
| 摸摸它·挥爪回应 | `Petting` 完成后自动衔接 | 再播放 3 秒 `Petted`：猫咪张嘴露出短舌、同侧前爪只完成一次从高到低的温柔摆动；尾巴作为独立图层上下摆动两个完整来回，起止角速度为零，不带动或变形身体。左右朝向都使用固定尾根、渐进弯曲和臀部重叠连接区，避免摆动时尾根与身体分层。动作首尾增加站立保持段和多段运行时中间帧。“喵～”及白色描边整体缩为上一版的 2/3，结束后平滑回到站立 |
| 算数 | 右键气泡中的“算数”或托盘“算数” | 只打开或重新显示计算器，不触发额外动画；猫咪当前的站立、待机、互动或睡眠流程继续运行，不会被强制切换或重置 |
| 哄睡它·双次顺毛 | 右键气泡中的“哄睡它” | 前 2 秒 `SoothingStroke` 使用 8 个独立手掌形态，每次从猫耳高度开始，沿肩背向身体下方顺毛，两次抚摸的下端终点与原版一致。手指开合、掌面贴合和手腕角度随接触变化；猫咪复用原始站立开眼/闭眼轮廓，仅逐渐加深困意，不缩短、压扁或改变胖瘦 |
| 哄睡它·进入睡眠 | 两次顺毛完成后直接衔接 | 接着 1 秒 `SoothedLoweringToSleep`：手掌淡出后，从抚摸末尾相同的闭眼姿态直接趴下、蜷缩并用尾巴包身，平滑进入 `Sleeping`。不再播放伸懒腰；哄睡总时长为 2 + 1 = 3 秒，随后保留 `Zzz` 和“叫醒它”功能 |
| 保持清醒 | 右键气泡侧边、“退下”下方的淡绿色圆形开关 | 圆内分行显示“保持／清醒”；点击后变为“取消保持／清醒”，定时待机到达原本的特殊睡眠节点时改为普通舔爪，不再自动入睡；手动“哄睡它”仍可正常入睡。再次点击不会立刻强制睡眠，而是在下一个符合条件的五分钟节点恢复特殊睡眠。选择会保存到本地配置，睡着时隐藏此开关，需先叫醒 |

亮屏计时使用 Windows 的显示器电源状态通知。熄屏、系统挂起、睡眠状态和醒来过渡不会消耗下一个五分钟周期。

所有带序号的待机动画均为低优先级。若待机动画1的 60 秒节点与五分钟默认舔爪或第六次特殊睡眠节点冲突，默认/特殊待机会直接顶替待机动画1；被顶替的本次 60 秒动作会被消费，不会在高优先级动作结束后立即补播。若高优先级节点在待机动画1进行的 1.5 秒内到达，程序也会立即切换到高优先级动作。触发秒数由 `idleAnimation1Seconds` 保存，正式默认值固定为 `60.0`。

所有定时动画统一由 `IdleScheduleCoordinator` 调度：默认/特殊待机 > 待机动画1 > 随机摇尾 > 随机摇耳；手动互动和拖动阻止新的定时动作。每个到点事件无论是否成功播放，都会重新计算自己的下一次触发时间；被覆盖不增加实际完成次数，也不排队补播。未到点的其他计时器不被无故清零。摇尾与摇耳分别使用独立的随机时钟，各自动画正在播放的 2 秒不计入自己的下一次随机等待，正常结束或中断时重新抽取 10–20 秒间隔。若到点被其他动作覆盖，也会立即重新随机计时，结束后不补播。因此无冲突时同一种随机动画两次开始通常相隔 12–22 秒，有冲突时实际间隔可能更长。熄屏、睡眠和醒来过程继续暂停待机计时，醒来后重新开始周期。

“保持清醒”只改变调度器对自动特殊睡眠的选择，不重置已经累计的计时和完成次数，也不禁用手动哄睡。启用期间每个原睡眠节点仍会按时被消费并播放普通舔爪；取消后从当时的计时继续，到下一个默认五分钟节点再恢复特殊睡眠。配置键为 `keepAwake`，默认值为 `false`。

## 鼠标目光跟随

猫咪处于普通站立时会注视鼠标，不需要先把鼠标移到桌宠上；鼠标位于桌面或其他应用窗口内也有效。只调整眼眶内部的虹膜、瞳孔及其高光，眼眶、脸部、体型和左右异瞳颜色保持不变。视线小幅平滑跟随，不会瞬间跳到鼠标方向，也不会把瞳孔移出眼眶；鼠标靠近两眼中心时自然回正。

拖动、收势、摇尾和摇耳待机、舔爪、摸摸、哄睡、入睡和醒来等状态使用各自原有的眼部表情，暂停鼠标跟随。恢复普通站立后重新平滑追踪；普通眨眼期间不会叠加睁眼瞳孔。进出特殊动作仍沿用统一姿态融合，保留过渡来源的注视方向。

实现复用现有动画刷新时钟，只在允许跟随时读取 Windows 当前鼠标坐标，由 WPF 换算到缩放后的猫咪局部坐标，不监听键盘、不记录鼠标轨迹、不联网。鼠标移动不更改待机计时或特殊动作优先级；关闭桌宠后没有独立跟踪进程。`--verify-gaze` 检查方向、缩放、平滑性、眼外像素不变、所有特殊状态及眨眼互斥，并生成 `tests/snapshots/17-gaze-*.png`。

## 统一动画连贯性

所有现有状态都通过同一套 `AnimationTransitionProfile` 切换：先保留上一姿态，再在 120–340 毫秒内用五阶 `smootherstep` 缓动融合到新姿态，使开始与结束均为零速度、零加速度。动作内部不再四舍五入跳到某张图片，而是在相邻关键帧间融合；“摸摸它”的挥爪回应使用站立—抬爪—中位—落爪—站立五段专用时间轴及较长运行时中间帧，`Petting` 与 `Petted` 之间另有 300 毫秒融合，`Petted` 返回站立使用 340 毫秒融合。睡醒与哄睡序列同样包含专用中间帧。

哄睡的两段直接交接使用 300 毫秒缓动（包含在 1 秒入睡段内，不额外延长动作）。哄睡专用序列会复制原有入睡帧，并仅将首帧替换为抚摸末尾的闭眼站立图，避免突然恢复睁眼站立；相邻趴下帧沿用短窗口融合，避免长时间双重轮廓，最后逐渐接入睡眠呼吸。普通定时入睡的原始序列不变。快照测试在左右两侧及三个呼吸相位下逐像素检查两处边界。

后续新增动画也必须沿用这套规则：首帧与来源状态兼容、末帧与目标状态兼容；大幅改变朝向或重心时提供专用中间帧；循环动作保证首尾基线与轮廓兼容；不能用一帧直接替换另一帧。完整标准见 `docs/animation-spec.md`。

## 天气与日期

日期始终读取电脑本地时间。天气通过 [Open-Meteo Forecast API](https://open-meteo.com/en/docs) 按现有经纬度读取，国家地区配置保持不变。桌宠启动时预加载天气，后台每 30 秒检查是否需要更新，成功数据默认每 15 分钟刷新；同一时间的重复请求会合并。

2026-09-03 已复现并修复旧 .NET 默认 `Ssl3, Tls` 导致的 HTTPS 握手失败，同一接口使用 TLS 1.2 实测 HTTP 200。没有关闭证书校验，也不修改系统网络配置。原先吞掉异常而无限“天气加载中”的逻辑已移除。最后成功结果保存在 `config/weather-cache.json`，重新打开气泡或重启桌宠可立即显示缓存；过期结果标注“缓存”，超过一天不再展示为天气。没有可用缓存且网络失败时明确显示“天气暂不可用”，30 秒后允许重试。错误诊断保存在 `config/weather-status.log`，来源与数据时间显示在天气卡片悬浮提示中。

气泡中的“国家－地区－天气情况”保持居中，后面为代码绘制的彩色动态图标：太阳光芒缓转、云朵轻移、雨滴下落、雪点飘落、雾带移动、闪电闪烁。显示时播放、隐藏或关闭时停止，不额外下载素材。日期仍单独显示在下一行。首次启动又没有缓存时仍需要等待实际网络请求，断网时不会伪造当前天气。

默认位置是上海。若要修改，复制 `config/settings.local.example.json` 为 `config/settings.local.json`，再修改：

```json
{
  "locationName": "你的城市",
  "countryName": "国家名称",
  "regionName": "省、直辖市或主要地区名称",
  "latitude": 0.0,
  "longitude": 0.0,
  "timezone": "Asia/Shanghai"
}
```

`settings.local.json` 不会被版本控制覆盖，后续更新代码时可以保留个人设置。

## 算数

右键互动气泡中的“算数”会打开一个本地虚拟计算器，同时保留原互动气泡而不将其隐藏。计算器的宽度、高度和缩放比例与点击当时的互动气泡一致，以气泡实际位置为锚点：优先完整放在气泡下方；靠近桌面底部或底部两个角时自动改到气泡上方；极端缩放下会比较上下剩余空间并将窗口限制在当前显示器工作区内。从托盘菜单打开时也先计算气泡理论位置，再使用同一套智能上下定位规则。

打开计算器不再触发歪头、捋耳或张嘴的特殊动画，也不重置猫咪的动作方向和待机计时。互动气泡、计算器自动上下定位、同步尺寸及原有按键功能保持不变。所有动画中的程序化双虎牙绘制层仍然移除。

计算器外观参考正方形虚拟计算机图像：深蓝色圆角机身、浅色数字显示屏、白色数字键、灰色功能键和橙色四则运算键。所有功能均在桌宠进程内离线执行，不打开浏览器、不访问网络，也不依赖任何账号或 API。

鼠标可以点击：

- 数字 `0–9`、小数点 `.`；
- 加 `+`、减 `−`、乘 `×`、除 `÷`、等号 `=`；
- 清除 `AC`、正负号 `±`、百分比 `%`；
- 记忆清除 `MC`、记忆读取 `MR`、记忆加 `M+`、记忆减 `M−`。

计算引擎支持连续运算、重复等号、小数、负数、百分比、独立记忆区和除零错误提示。数字键盘也可辅助输入；按 `Esc` 或计算器右上角的圆形 `×` 可以关闭计算器。

## 替换为原型角色

程序会自动读取 `assets/character` 下的透明 PNG：

```text
assets/character/
├── stand/
├── drag_side/
├── drag_transition/
├── lick/
├── sleep_transition/
├── sleep/
├── wake/
└── pet/
```

每个目录按文件名排序播放，建议使用 `000.png`、`001.png`。相邻关键帧会自动短窗口融合，状态之间会自动套用统一缓动；仍建议为大幅转向、起身、趴下等动作提供真正的中间姿态，而不是只依赖透明度混合。详细的正式素材约束见 `docs/animation-spec.md`。

本项目对应的个人 ImageGen 模板为 `$artifact-template-pixel-calico`，展示名是 `Pixel Calico 三花猫桌宠`。在提示词中同时加入 `$imagegen` 和该模板，再描述要补充的动作即可复用同一参考图。完整生成提示规范记录在 `docs/imagegen-prompts.md`。

## 开发与验证

只编译：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

编译并检查关键文件、配置与状态标记：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

核心结构：

- `PetWindow.cs`：透明窗口、鼠标拖动、亮屏计时与动作状态机。
- `CatVisual.cs`：正式 PNG 帧播放器和程序化开发猫。
- `InteractionBubbleWindow.cs`：自适应左右位置、跟随桌宠缩放的蓝色立体云朵互动气泡。
- `CalculatorWindow.cs`：与互动气泡同尺寸、同位置的深蓝虚拟计算器界面和鼠标按键。
- `CalculatorEngine.cs`：离线小数、四则运算、百分比、正负号、重复等号与记忆功能。
- `CalculatorVerifier.cs`：计算功能自动验证。
- `WeatherService.cs`：实时天气与日期。
- `ScreenPowerTracker.cs`：Windows 显示器电源状态通知。
