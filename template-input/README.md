# 当前猫咪身份参考

- `pixel-calico-heterochromia.png`：后续动画的首要像素基准，256×256 真透明，保留原始体型和每个非虹膜像素。
- `cat-reference.png`：ImageGen 更新后的异瞳照片参考。
- `cat-heterochromia-imagegen.png`：ImageGen 虹膜配色来源图；仅作颜色参考，不用其背景或重新绘制的轮廓替换游戏帧。

正面画面左眼保留黄绿色，右眼淡蓝色。右侧身走路显示原色眼，左侧身显示淡蓝眼；闭眼时不应出现彩色线条。原始用户照片 `../猫.jpg` 不作眼色基准，修改前素材备份在 `../source-art/pre-heterochromia`。

本次使用内置 ImageGen（不是 API/CLI），提示词和处理规则见 `../docs/heterochromia-update.md`。
