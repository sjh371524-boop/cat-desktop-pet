# 角色素材契约

当前素材版本为 11（异瞳三花）：首要参考 `reference/pixel-calico.png`，对应项目 `template-input/pixel-calico-heterochromia.png`。正面左眼黄绿色、右眼淡蓝；左右转向保持同一解剖学眼睛的颜色。原始照片仅归档，不可重新将两眼都做成黄绿色。

随机摇尾待机复用 `stand/000.png`、`stand/001.png` 与独立尾巴层，无新体型或背景。固定 2 秒两个轻柔来回，第一回结束和第二回开始时眨眼。每次结束后随机等待 10–20 秒，最低优先级，被覆盖不补播。

93 张既有帧已审查并同步适用的虹膜颜色，闭眼帧不绘制虹膜；新增 `drag_side/left_open` 和 `left_blink`，用于保留左右侧身的眼色区别。既有 8 张动作图集已从更新后的精灵帧重新合成透明图集，原始输出与改动前素材移作来源备份 `source-art/pre-heterochromia`。最新 ImageGen 提示词见 `docs/heterochromia-update.md`。

哄睡每次顺毛起点已从肩部升至猫耳高度，下端终点不变。摸头后的 3 秒喵叫伸爪中，尾巴以独立图层上下两个完整来回，身体保持原始像素与比例。

此目录保留给原型图片衍生出的透明 PNG 动作帧。程序会按文件名顺序读取以下子目录：

- `stand`：正面站立、呼吸和眨眼循环。
- `drag`：拖动时四脚交替前后移动；帧速率由鼠标位移决定。
- `lick`：2 秒坐下、伸爪和舔爪动画。
- `sleep_transition`：2 秒缓缓趴下并蜷缩的动画。
- `sleep`：蜷缩睡眠循环；程序另外绘制跟随的 `Zzz`。
- `wake`：2 秒逐渐醒来并恢复站立。
- `pet`：被摸后的反应。
- `stand/000.png` 与 `stand/001.png`：同时作为哄睡第一段的固定体型开眼/闭眼母版；运行时只叠化眼睑，不再使用会让身体逐帧变扁的旧 `drowsy` 帧。
- `../ui/soothing_hand`：哄睡第一段的 8 张完整手掌形态；两次顺毛期间指尖、掌面和手腕都有连续变化。
- 哄睡入睡段复用 `sleep_transition`，在内存副本中用 `stand/001.png` 替换睁眼首帧，并以 `sleep/000.png` 结束；抚摸 2 秒后直接进入 1 秒趴下入睡，不再播放伸懒腰。

旧 `calculator_greeting`、`soothe_sleep/stretch`、`soothe_sleep/stretch_v2` 及其原始动作表只保留为历史素材，不再注册或由渲染器加载。打开“算数”不再触发猫咪特殊动画。

要求所有帧使用一致画布、角色比例和脚底基线，背景必须是真透明 Alpha，不得使用棋盘格伪透明。建议文件名使用 `000.png`、`001.png` 等三位数字。

当前目录已经包含以 `猫.jpg` 中三花猫为身份参考生成的正式像素帧。运行时使用的独立动作帧均为 `256×256 RGBA`，脚底基线经过统一对齐，程序使用最近邻缩放。ImageGen 原始动作表保留为版本化文件；`scripts/prepare-chroma-sprite-sheet.ps1` 会执行绿幕透明化、边缘残色清理和六像素安全边距检查，手掌表还会只保留最大连通主体，从而删除跨格截入的小碎片。`scripts/prepare-soothe-sleep.ps1` 现在只重新生成当前哄睡手掌帧，不再生成伸懒腰帧。
